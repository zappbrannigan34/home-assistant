# Пакет `ack_reminders` — Гарантированные напоминания с обратной связью

Изолированный пакет Home Assistant (`packages/ack_reminders/ack_reminders_control.yaml`) для надёжных напоминаний 24/7 с разделением **Подтверждения (ACK)** и **Отсрочки (Snooze)** и 3-ступенчатой лестницей эскалации.

## Ключевые принципы и ограничения

1. **4 независимых слота**: `tg` (упоминания в Телеграме), `meeting` (утреннее совещание), `pill` (таблетки по плавающему сну), `custom` (произвольные/тестовые напоминания).
2. **Сохранность при перезапуске HA**: все `input_*` объявлены **без `initial:`**, все `timer:` — с **`restore: true`**. Стартовые значения выставляются один раз автоматизацией `ack_startup_init_and_restore` по флагу `input_boolean.ack_defaults_initialized`.
3. **Строгий таргетинг устройств**:
   - Голос на Яндекс.Станции — **строго только** `media_player.yandex_station_m105j4010yy1mk` (`Станция Мини zap`) через `media_content_type: text` с `extra.volume_level` (автовозврат прежней громкости силами Glagol, без открытого микрофона).
   - Пуши и `clear_notification` — **строго только** `notify.mobile_app_zapphone` (`masy` не затрагивается).
   - Telegram-сообщения и inline-кнопки — `notify.telegram_bot_8110302509_1002715853345` (`Срочные уведомления`).
4. **Режим работы 24/7**: деления на день и ночь нет.

## Лестница эскалации (`script.ack_reminder_start`)

- **Ступень 1 (`0 с`)**: сообщение в Телеграм с кнопками `[✅ Принял]` / `[⏸ Отложить]` + обычный пуш на телефон с кнопками и `clickAction` (если задан URL).
- **Ступень 2 (`45 с`)**: если слот активен и не отложен — озвучка `TTS` в потоке `alarm_stream_max` на телефоне + следом визуальный `persistent` пуш `alarm_stream_max` с кнопками + голосовое объявление на `Станция Мини zap` + двойное мягкое мигание `light.light_bathroom` с возвратом исходного состояния (если есть движение в ванной).
- **Ступень 3**: повторы Ступени 2 по графику `[2, 2, 3, 5, 5, 5, 10, 10, 15, 15, 15, 15]` мин до подтверждения или отсрочки.

## Способы подтверждения и отсрочки

- **Кнопки в Телеграме**: `/ack_<slot>` и `/snooze_<slot>`.
- **Кнопки на экране блокировки телефона**: `ACK_<SLOT>` и `SNOOZE_<SLOT>`.
- **Голос через Алису (Yaha Cloud)**: виртуальные переключатели `input_boolean.ack_voice_confirm` («Подтверждение уведомления»), `input_boolean.ack_voice_pill_taken` («Приём таблетки»), `input_boolean.ack_voice_snooze` («Отсрочка уведомления»).
- **Авто-отбой для слота `tg`**: вебхук `action: "auto_ack"` при ответе или прочтении в активном чате.
- **Bluetooth-кнопка по MQTT**: топик `homeassistant/ack_reminders/ble_button` (`single` — подтверждение или досрочная отметка таблетки, `double` — отсрочка).

## Сценарии

1. **Вебхук Телеграма** (`webhook_id: !secret ack_reminders_webhook_id`): поддерживает `heartbeat`, `trigger_mention` (с дедупликацией по `event_id`), `auto_ack`.
2. **Утреннее совещание**: `09:55:00` по рабочим дням РФ (`binary_sensor.workday_sensor == 'on'`), отсрочка по умолчанию `4` мин.
3. **Таблетки под плавающий график сна**: детектор активности (датчики движения, свет ванной/коридора/комнаты, снятие `zapphone_2` с зарядки). Перерыв `>= ack_sleep_gap_hours` (`4` ч) запускает `timer.ack_pill_wakeup_delay` (`15` мин) -> сигнал 1-й таблетки -> после подтверждения старт `timer.ack_pill_dose2_gap` (`ack_pill_interval_hours`, по умолчанию `13` ч) -> сигнал 2-й таблетки.

## Деплой и проверка

- Файл пакета копируется в `\\192.168.88.42\config\packages\ack_reminders\ack_reminders_control.yaml`.
- Дашборд `dashboards/ack_reminders_dashboard.yaml` регистрируется в `configuration.yaml` под ключом `ack-reminders`.
- Валидация через `/api/config/core/check_config` и штатный перезапуск Home Assistant.
